# GitHub Pages — privacy policy hosting

This folder is the whole site. One file, no build step.

## Publish

1. Open <https://github.com/new>.
2. Repository name: `chainreaction-legal`.
3. Visibility: **Public**. Public is required on free GitHub accounts for Pages.
4. Create the repository.
5. Click **Add file → Upload files**, drag `index.html`, commit to `main`.
6. Open **Settings → Pages**.
7. Source: **Deploy from a branch**. Branch: `main`, folder: `/ (root)`. Save.
8. Wait 1–2 minutes. The URL is:

   `https://sherveymaverick-cloud.github.io/chainreaction-legal/`

9. Open the URL in a private window. It must load without signing in.
10. Paste that URL into Play Console → Store listing → Privacy policy, and into
    App content → Privacy policy.

## Update later

Edit `index.html` in the repository, commit, wait a minute. The same URL keeps
working.

## Check before submitting

- Page opens over HTTPS with no warning.
- Contact email is visible.
- Effective date is current.
- No broken layout at phone width.
